Projeto criado para o desenvolvimento de um app personalizado para o cadastro e acompanhamento de:
* Exercícios físicos diários:
    + Cárdio: Elíptico e corrida de rua
* Consumo de água por dia
* Controle de peso

Aplicativo atende as necessidades específicas de uma usuária que já tinha uma rotina ativa e que realizava este controle manualmente. 
A partir do app será possível com maior facilidade:
* Acompanhar o aumento do condicionamento físico
* Controlar a variação de peso
* Observar uma ABA o histórico dos dados já cadastrados
